# Field editorial redesign

## Design read — 22 September 2026

An engineering company website for contractors, operators and integration partners: real construction work, precise information and a confident, human editorial rhythm. The preserved brief supplies the business content; the user's latest direction adds workers, video and richer interaction. The existing embuilded.com is a visual reference, not approval to import its claims or contact details.

- DESIGN_VARIANCE: 8 — asymmetric photographic compositions and numbered solution rows replace repeated feature cards.
- MOTION_INTENSITY: 5 — deliberate entrances, interactive row emphasis and an optional short film. No autoplay, scroll hijacking or simulated telemetry.
- VISUAL_DENSITY: 4 — generous image areas with compact navigation and readable technical copy.

## Audit and response

The previous version repeats condensed uppercase headings and grey panels, while one distant site image carries most of the visual identity. Use sentence-case Geist headings, warm paper, charcoal and restrained oxide orange. Pair building scale with workers assembling reinforcement. Keep all existing sections, copy, destinations and bilingual behavior.

Use individually verified Pexels media under the Pexels License alongside the existing CC0 library. Label stock scenes as illustrative, not company projects or staff. Store optimized assets locally with source, license and checksum records. Video loads only on explicit request, has native controls and a readable scene description, and retains a poster if playback fails. Remove source audio; this contextual film communicates visually without speech.
